These fonts are embedded in PDF notes downloads to support English and Hebrew.
They are loaded only when a PDF is requested.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf

The SIL Open Font License is included in OFL.txt. Noto Sans supplies Latin text,
punctuation, and italics. Noto Sans Hebrew supplies Hebrew glyphs; Hebrew text
uses its upright glyphs when Latin text is italicized.
